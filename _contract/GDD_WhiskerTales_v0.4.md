## 1. Vision
**One-liner:** "หนังสือนิทานสีไม้ที่แมวโมจิผจญภัยแทนเรา — เปิดมาเมื่อไหร่ก็มีของใหม่รอ"
1. **One Thumb, Zero Pressure** — นิ้วโป้งเดียวโซนล่าง 40% · ไม่มีอะไรลงโทษการไม่เข้าเกม · โฆษณาเป็นทางเลือกเสมอ ไม่ดูก็เล่นได้ครบ
2. **Fail Forward** — แพ้บอสไม่เสียอะไร ถอยไปฟาร์มต่อ
3. **Two-Layer Depth** — เด็กดูแมวสู้ + ถักของ / ผู้ใหญ่ปั้น build stat-anti-stat + สกิล + เพื่อนสัตว์
4. **Paper is Alive** — art direction v0.3 §9 ทั้งหมด

## 2. Core Loop

### 2.1 Macro
```
เปิดแอป → รับรางวัลออฟไลน์ (ปลาทอง + ไหมพรม + EXP + ไข่เพื่อนสัตว์บางครั้ง)
  → ถักของในตะกร้า → สวมของดีกว่า / รีไซเคิล
  → ฟักไข่เพื่อนสัตว์ (ไข่ที่ดรอป / ฟรีจากโฆษณา / ปลาทอง)
  → อัพสกิล/เพื่อนสัตว์/ห้องสมุด (เร่งด้วยโฆษณาได้) → พลังแมวขึ้น
  → ท้าบอสหน้าถัดไป → ผ่าน = เปิดหน้านิทานใหม่
  → (ทางเลือก) โหมดนิทานผจญภัย 3–5 นาที
  → ปิดแอป → โมจิฟาร์มต่อ (offline)
```

### 2.2 Micro — Auto-Battle บนหน้านิทาน
- โมจิซ้าย เดินขวาอัตโนมัติ ฉาก parallax (v0.3 §3.2) — เจอ**คลื่นมอน**สู้อัตโนมัติไม่มีวันจบ
- โลก: **เล่ม → บท → หน้า** หน้าละ 5 คลื่น + บอสหน้า (ท้าเมื่อพร้อม)
- แพ้บอส → ฟาร์มคลื่นต่อ ไม่มีโทษ · แตะสกิลเอง/dodge = โบนัส ไม่บังคับ

| ใช้ | **ไหมพรม** 1 ม้วน/ครั้ง — ได้จากสู้/ออฟไลน์/ภารกิจ/โหมดผจญภัย · **ห้ามขายด้วยเงินจริงทุกรูปแบบ** |
| เลือกช่อง | ผู้เล่น**เลือกช่อง**ที่จะถัก (8 ช่อง: หมวก ผ้าพันคอ เสื้อ ปลอกแขน รองเท้า กระดิ่ง กระเป๋า ของเล่น) หรือกด "สุ่มช่อง" ได้โบนัส EXP ตะกร้า +50% |
| เกรด | 6 สี (ขาว→เขียว→ฟ้า→ม่วง→ทอง→รุ้ง) ตาม**ตารางเลเวลตะกร้าที่โชว์ในเกม** (ดู §15.4) |

| เทียบ | การ์ดซ้าย-ขวา + ลูกศรเขียว/แดง · ดีกว่าทุก base stat → ดาว ✨ |
| ตัดสินใจ | สวม / รีไซเคิล (ได้ปลาทอง + EXP ตะกร้า) |
| ตะกร้าเลเวลอัพ | EXP จากการถัก+รีไซเคิล → ตารางเกรดดีขึ้น |
| การันตี | ทุก 30 ครั้งได้เกรด ≥ ม่วง (ตัวนับโชว์บนตะกร้า) |
| **Auto-craft (MVP)** | ปลดหลังบท 1: ตั้งช่องที่ต้องการ (หลายช่องวนได้) + เกรดขั้นต่ำ + affix ที่อยากได้ ≤2 → ไม่ผ่านรีไซเคิลเอง · ผ่าน/ดีกว่าแน่นอน → หยุดรอผู้เล่น · ทำงานเฉพาะตอนเปิดเกม |
| ตีบวกตามช่อง | อัพเกรด**ช่อง** ไม่ใช่ชิ้น — เปลี่ยนของไม่เสียการลงทุน |

## 4. Combat & Stats

### 4.1 Stats
| ชั้น | Stat | คู่ anti-stat |
|---|---|---|
| หลัก | ❤️ HP · ⚔️ ATK · 🛡️ DEF · ⚡ ความเร็วตี | — |
| รอง | คริ / แรงคริ | กันคริ / ลดแรงคริ |
| | ตีติด | กันตีติด |
| | สวนกลับ | กันสวน |
| | มึน | ต้านมึน |
| | หลบ | แม่นยำ |
| | ดูดเลือด | ต้านดูดเลือด |
| UI | **พลังแมว 🐾** ตัวเลขเดียว (สูตรใน §15.2) |

### 4.2 Damage shape
- `base = max(ATK − DEF, ATK × 5%)` — DEF แบบลบ แต่ floor 5% ของ ATK (เจ็บเสมอ ไม่มีเลข 0)
- สุ่ม hit **ครั้งเดียว** แบ่ง หลบ/ปกติ/คริ · คริ ×`max(1.5, แรงคริ − ลดแรงคริ)`
- proc รอง = `clamp(stat − anti, 0, cap)` · cap: คริ 60%, ตีติด/สวน/หลบ 40%, มึน 25%
- Deterministic sim (fixed-point + seeded RNG) → คำนวณออฟไลน์ได้โดยไม่ต้องมี server

### 4.3 Buff engine (ใช้ร่วมทุกโหมด)
- Buff = `action` + `params` (JSON) → class override เฉพาะ hook (onBegin/onEnd/onTick/onDamageDealt/onDamageTaken/onHeal/onStateEvent)
- State events ให้ buff ยิง buff ต่อ → synergy เป็น data · object pool · relic/talent โหมดผจญภัยใช้ engine เดียวกัน

## 6. เพื่อนสัตว์ 🐦🐭🐸 + Gacha ฟักไข่ 🥚

### 6.1 เพื่อนสัตว์
- unit จริงในสนาม (partner damage) — ช่องออกรบ 1→3 ปลดตามบท
- อัพเลเวลด้วยขนม 🍪 · ตัวซ้ำ → ดาว (★1–5) · passive ตอนครอบครอง + bonus ตอนออกรบ
- MVP: **6 ตัว** — ธรรมดา 3 / หายาก 2 / ตำนาน 1

### 6.2 ฟักไข่ (gacha) — ตาม YK
| ช่องทาง | จำนวน | ต้นทุน |
|---|---|---|
| 🥚 ไข่ที่ดรอป | ไม่จำกัด (ตามที่มี) | ไข่ 1 ใบ/ครั้ง — ดรอปจากบอสหน้า 100%, บอสบท 3 ใบ, คลื่นปกติ 1%, ออฟไลน์ |
| 📺 ดูโฆษณา | **3 ครั้ง/วัน** | ฟรี (rewarded ad) |
| 🐟 ปลาทอง | **5 ครั้ง/วัน** | ครั้งที่ 1–5 = 300 / 450 / 675 / 1,000 / 1,500 (×1.5) — scale ตามบท §15.5 |

- อัตรา (โชว์ในเกมก่อนกดทุกครั้ง): ธรรมดา 75% / หายาก 22% / ตำนาน 3%
- การันตี: ทุก 40 ครั้งได้ตำนาน (ตัวนับโชว์ + ข้ามวันไม่รีเซ็ต)
- รีเซ็ตโควต้า: เที่ยงคืนเวลาเครื่อง
- **เส้นห้ามข้าม:** ไข่ + ปลาทองห้ามขายด้วยเงินจริง และห้ามใส่ใน IAP bundle ใด ๆ — ถ้าข้าม = paid loot box ทันที (ดู §14)

## 7. ห้องสมุดนกฮูก 🦉 (research tree)
- tree ถาวร: stat + ปลดฟีเจอร์ (auto-craft, ช่องสกิล/เพื่อน, offline cap, คิวที่ 2)

## 14. Compliance ที่ต้องทำเพราะเพิ่มโฆษณา + gacha ⚖️
> ไม่ใช่คำปรึกษากฎหมาย — เป็น checklist ที่ต้องยืนยันกับ policy ปัจจุบันของแต่ละ store ก่อน submit

1. **ขัดกับ v0.3 §12.3 ตรง ๆ:** v0.3 ห้าม 3rd-party SDK ที่เก็บ identifier — ad SDK ส่วนใหญ่เก็บ → ต้องแก้ข้อนี้ + Privacy Policy TH/EN + Data Safety (Play) + Privacy Nutrition Label (App Store) ใหม่
2. **กลุ่มเป้าหมายมีเด็ก 5 ขวบ** (v0.3 §2): ถ้า Play Console ระบุกลุ่มเป้าหมายรวมเด็ก → อยู่ใต้ **Google Play Families Policy** → ใช้ได้เฉพาะ ad SDK ที่อยู่ในรายการ Families self-certified, ห้ามโฆษณาแบบ personalized/behavioral กับเด็ก, เนื้อหาโฆษณาต้องเหมาะกับเด็ก
3. **COPPA (ผู้ใช้สหรัฐฯ อายุ <13):** ส่ง flag child-directed / ไม่เก็บ advertising ID จากเด็ก — ต้องมี age screen แบบเป็นกลางตอนเปิดครั้งแรก แล้วเปิดโหมด non-personalized สำหรับ <13
4. **iOS:** ถ้าจะใช้ IDFA ต้องมี ATT prompt — แนะนำ**ไม่ขอ ATT เลย** ใช้ non-personalized อย่างเดียว (เกมเด็ก + ลด friction)
5. **Gacha:** โชว์อัตราในเกมก่อนกดทุกครั้ง · สกุลที่ใช้ฟักต้องซื้อด้วยเงินจริงไม่ได้ตลอดไป (ถ้าวันหนึ่งขาย → ต้องผ่านกฎ loot box ของ Apple 3.1.1 และกฎหมายบางประเทศ เช่น เบลเยียม)
6. **Rewarded ad ต้อง opt-in ชัดเจน:** ปุ่มบอกว่าเป็นโฆษณา, ไม่บังคับดู, ไม่หลอกกด, ปิดได้ตาม SDK
7. LoM ใช้ AppLovin / Unity Ads / PAG — **ไม่ใช่เหตุผลให้เราใช้ตาม** ต้องเลือกจากรายการ Families-certified ณ วันที่ integrate

## 15. Balance Proposal (Q5) — curve ของเราเอง

> **Source of truth ของตัวเลข = `design/balance/idle_balance_v1.json`** — ตารางใน §15.1–15.6 เป็นค่าตั้งต้นตอนร่าง ถ้าขัดกับ JSON ให้ยึด JSON · sim: `tools/balance_sim` (§15.8)

### 15.0 ทำไมไม่ใช้ตัวเลขของ LoM
- ตารางค่าของ LoM ถูกเข้ารหัสไว้ตั้งใจ — ถอดมาใช้ = เอาข้อมูลที่เป็นทรัพย์สินเขามาใช้ตรง ๆ (research §0)
- ตัวเลขเขาจูนรอบ **ระบบจ่ายเงิน** (draw แบบเติมเงิน, VIP, privilege card, battle pass) ที่เราไม่มี → ยกมาก็ไม่บาลานซ์กับเศรษฐกิจเรา
- สิ่งที่เอามาได้คือ**รูปทรง** (DEF แบบลบ, stat คู่, ตะกร้ามีเลเวล, ตีบวกตามช่อง) ซึ่งใส่ไว้แล้วข้างบน — ตัวเลขด้านล่างตั้งต้นเอง แล้วจูนด้วย balance sim + playtest

### 15.1 เป้าจังหวะ (pacing targets)
| ช่วง | เป้า |
|---|---|
| หน้า 1–10 (บท 1) | ผ่าน 1 หน้า ~3–5 นาทีออนไลน์ — จบบท 1 ในวันแรก |
| หน้า 11–20 (บท 2) | 1 หน้า ~15–30 นาที (รวมออฟไลน์) — ~3 วัน |
| หน้า 21–30 (บท 3) | 1 หน้า ~2–4 ชม. — ~10 วัน · จบเล่ม 1 ≈ **2 สัปดาห์** |
| ตัวเลข | พลังแมวปลายเล่ม 1 ≈ 20K–30K (บอสบท 3 ≈ 2.2 × 12K ≈ 27K) → แสดงแบบ "27.4K" (เด็กอ่านตัวเลขสั้นได้) |

### 15.2 พลังแมว
~~`Power = ATK×5 + HP×0.5 + DEF×3 + Σ(stat รอง% × 100 × น้ำหนัก)`~~ → **แก้ใน D-011:** `Power = (ATK×5 + HP×0.5 + DEF×3) × (1 + Σ stat รอง% × น้ำหนัก)` (สูตรเดิมทำให้ affix ชิ้นเดียวมีค่ามากกว่า ATK จริงหลายเท่า → ถักอัตโนมัติเลือกของผิด) — น้ำหนัก: คริ 1.2, แรงคริ 0.6, ตีติด 1.0, สวน 0.8, มึน 1.0, หลบ 0.9, ดูดเลือด 0.7

### 15.3 ศัตรู
- พลังคลื่นหน้า n: `P(n) = 100 × 1.18^(n−1)` → หน้า 10 ≈ 440 · หน้า 20 ≈ 2.3K · หน้า 30 ≈ 12K
- บอสหน้า = 1.5×P(n) · บอสบท = 2.2×P(n)
- แบ่งพลังเป็น HP:ATK ของมอน = 60:40 (ตายใน 3–6 ครั้งตีถ้าพลังเท่ากัน)

### 15.4 ตะกร้า (ตารางเกรด % — โชว์ในเกม)
| เลเวลตะกร้า | ขาว | เขียว | ฟ้า | ม่วง | ทอง | รุ้ง | EXP สู่เลเวลถัดไป |
|---|---|---|---|---|---|---|---|
| 1 | 70 | 25 | 5 | 0 | 0 | 0 | 20 |
| 5 | 40 | 35 | 20 | 5 | 0 | 0 | 120 |
| 10 | 15 | 30 | 35 | 17 | 3 | 0 | 400 |
| 15 | 5 | 15 | 35 | 33 | 11 | 1 | 900 |
| 20 (MVP max) | 0 | 5 | 25 | 42 | 23 | 5 | — |
- ตัวคูณ base stat ตามเกรด: 1.0 / 1.4 / 2.0 / 2.8 / 4.0 / 5.6
- รายได้ไหมพรม: ดู `income.ASSUMPTION_yarn_per_wave` ใน JSON (ปัจจุบัน 0.1/คลื่น, +2%/หน้า) · ออฟไลน์เท่ากัน

### 15.5 ฟักไข่ — ราคาปลาทอง
- `ราคาครั้งที่ k (k=1..5) = 300 × 1.5^(k−1) × (1 + 0.08 × (บทปัจจุบัน − 1))`
- ทำให้ใช้ปลาทองฟักครบ 5 ครั้ง ≈ 15–20% ของรายได้ปลาทองต่อวัน (ต้องเลือกระหว่างฟักไข่กับห้องสมุด = การตัดสินใจที่มีความหมาย)

### 15.6 ห้องสมุด
- เวลา node เลเวล L: `t(L) = 1 นาที × 1.6^(L−1)` cap 4 ชม. · ราคา `100 × 1.45^(L−1)` ปลาทอง
- โฆษณา 5 ครั้ง/วัน × (−30 นาที หรือ −25%) ≈ ลดเวลารวมได้ 2.5–5 ชม./วัน

### 15.7 Balance sim (`tools/balance_sim`)
- pure Dart ไม่มี dependency · อ่าน JSON ทั้งหมด · จำลองผู้เล่น 3 session × 15 นาที/วัน + ออฟไลน์ · เทียบ profile `no_ads` vs `full_ads` · 10–20 seed
- เป็น **pacing model** (เทียบพลังรวมกับ curve ศัตรู) ไม่ได้รัน combat engine จริง → ต้องจูนซ้ำใน T-029 หลังมี engine
- รัน: `cd tools/balance_sim && dart run bin/sim.dart --seeds 20 [--extra offline_x2,...]` · exit 0 = ผ่านทั้ง 2 เป้า

### 15.8 ผลรันล่าสุด (2026-10-12, 10 seeds, idle_balance_v1.json)
| profile | วันที่ผ่านหน้า 10 / 20 / 30 | พลังแมวตอนจบเล่ม | ผล |

> ⚠️ (รันก่อน D-003) **เป้า 2 ผ่านเพราะโฆษณาแทบไม่มีผล ไม่ใช่เพราะบาลานซ์ดี** — ใช้ได้จริงแค่ 5.1/8 เพราะ ad ลดเวลาวิจัยกดได้เฉพาะตอนมีงานวิจัยค้าง และวิจัยมักติดเพราะปลาทองไม่พอ · ผลรวม 20 seeds

**ข้อสังเกตที่ต้องแก้ใน T-029 (ยังไม่ถือว่า validated เต็ม):**
1. **ไวต่อค่ามาก** — `item_power_growth_per_page` 1.065 → 15.6 วัน แต่ 1.07 → 6.9 วัน · บท 3 เป็น "กำแพง" (ตะกร้าเต็มเลเวล 20 แล้วเหลือแต่อัพช่อง) → ต้องเพิ่มแหล่งพลังที่โตตามเวลาในบท 3 (เช่น node ห้องสมุดแรงขึ้น / ตะกร้าเลเวล 21–30)

4. ทุกค่าที่ขึ้นต้น `ASSUMPTION_` ใน JSON = สมมติฐานที่ GDD ยังไม่กำหนด
