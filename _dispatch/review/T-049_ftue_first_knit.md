# T-049: นาทีแรกไม่ต้องอ่าน (ถักหมวกแรกแล้วโมจิใส่)
Module: app/ui | Priority: P1 | Owner: Claude | Depends: ไม่มี

## Goal
เด็ก 5 ถึง 8 ขวบที่ยังอ่านไม่ออกต้องเจอ "จุดว้าว" ภายใน 30 วินาทีแรก: กดตะกร้า แล้วเห็นหมวกไปอยู่บนหัวโมจิจริง
ตอนนี้เกมไม่มีระบบสอนเล่นเลย และป้าย Auto-knit กับ "ของดีกว่า: เก็บรอเลือก" โผล่ตั้งแต่นาทีแรก
ที่มา: รีวิวความสนุกแบบ gstack 2026-11-21 ข้อ 1 (Player Impact 9/10)

## ขอบเขต
1. เปิดเกมครั้งแรก (หลังหน้าถามอายุ): อุ้งเท้าชี้เด้งเบาๆ ที่ปุ่มถักในตะกร้า ไม่มีข้อความ ไม่มีจอมืดบังเกม ไม่มีนับถอยหลัง
2. การถักครั้งแรกได้ **หมวก** เสมอ (ช่องที่เห็นบนตัว) และสวมให้ทันที พร้อมเอฟเฟกต์ที่หมวกลอยจากช่องไปติดหัวโมจิ
3. ถ้าเด็กไม่กดเลย อุ้งเท้าชี้ค้างไว้เรื่อยๆ เกมเดินต่อตามปกติ (idle ล้วน D-004 ไม่หยุดรอ)
4. ซ่อนปุ่ม Auto-knit และ "ของดีกว่า" จนกว่าจะผ่านหน้า 5 (ค่าใน JSON ไม่ hard-code)
5. จำใน save ว่าสอนแล้ว ไม่โผล่ซ้ำ · save เดิมที่เล่นเกินหน้า 5 แล้วไม่เห็นอุ้งเท้าและเห็นปุ่มครบ

## Acceptance Criteria
- [ ] save ใหม่: อุ้งเท้าชี้ปุ่มถักภายใน 3 วินาทีหลังเข้าหน้าหลัก
- [ ] กดครั้งแรกได้หมวก สวมทันที โมจิในฉากใส่หมวกนั้น · อุ้งเท้าหายไป
- [ ] ก่อนผ่านหน้า 5 ไม่เห็น Auto-knit และ "ของดีกว่า" · หลังผ่านเห็นทั้งคู่

- [ ] golden ใหม่: หน้าหลักตอนอุ้งเท้าชี้ และหลังสวมหมวกแรก (TH + EN)
