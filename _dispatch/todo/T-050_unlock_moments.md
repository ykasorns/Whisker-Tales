# T-050: จุดปลดล็อกเป็นฉาก ไม่ใช่แค่เสียง (เลือกคลาส Lv10 + จุดแดงบนเมนู)
Module: app/ui | Priority: P1 | Owner: Claude | Depends: ไม่มี (ทำหลัง T-049 ได้ดีกว่า เพราะแตะหน้าหลักเหมือนกัน)

## Goal
ช่วงที่น่าตื่นเต้นที่สุดของชั่วโมงแรกคือได้เลือกคลาสที่ Lv10 แต่ตอนนี้มีแค่เสียงเลเวลอัป (`game_shell.dart` ฟัง `levelUps` แล้วเล่นเสียงอย่างเดียว)
ตัวเลือกคลาสซ่อนอยู่ในแท็บแมว และแถบเมนูไม่มีจุดแดงบอกว่ามีของใหม่ เด็กจึงอาจไม่รู้เลยว่ามีให้เลือก
ที่มา: รีวิวความสนุกแบบ gstack 2026-11-21 ข้อ 2 (Player Impact 8/10)

## ขอบเขต
1. **ฉากเลือกคลาส:** เมื่อถึงเลเวลที่ปลดคลาส (อ่านจาก JSON) เปิดฉากเต็มจอ
   - โมจิ 4 ตัวใส่ชุดคลาส (ภาพ D-029) ให้แตะเลือก · แตะแล้วโมจิทำท่าโจมตีของคลาสนั้นให้ดู · ปุ่มยืนยันเป็นไอคอน
   - มีปุ่มปิด "ไว้ทีหลัง" · เกมเดินเบื้องหลังต่อ (ไม่หยุดรอ ไม่มีนับถอยหลัง)
   - ใช้ตอนกำลังสู้บอสไม่ได้ ให้รอจบไฟต์ก่อน (สอดคล้อง GDD v0.5 §3.1)
2. **จุดแดงบนแถบเมนู** (ไม่มีตัวเลข): ขึ้นเมื่อมีของที่ยังไม่ได้ดู และหายเมื่อเปิดดู
   - แท็บแมว: เลือกคลาสได้แต่ยังไม่เลือก, ปลดสกิลคลาสช่องใหม่, เพื่อนสัตว์ใหม่, วิจัยเสร็จ
   - หน้าหลัก: ช่องอุปกรณ์ปลดใหม่ (ช่องนั้นเด้งเบาๆ ครั้งเดียว)
3. **ฉลองเลเวลอัป** เบาๆ บนฉาก (ภาพหรือเอฟเฟกต์ที่มีอยู่แล้ว) ไม่ใช่ popup
4. จำใน save ว่าเห็นอะไรแล้ว · save เดิมที่เลือกคลาสไปแล้วไม่เห็นฉากเลือกคลาส

## Acceptance Criteria
- [ ] save ใหม่ถึง Lv10: ฉากเลือกคลาสเปิดเอง 1 ครั้ง · เลือกแล้วโมจิบนหน้าหลักใส่ชุดคลาสนั้น
- [ ] กด "ไว้ทีหลัง": ฉากปิด แท็บแมวมีจุดแดงจนกว่าจะเลือกคลาส
- [ ] ถึง Lv10 ระหว่างสู้บอส: ฉากเปิดหลังไฟต์จบเท่านั้น
- [ ] จุดแดงขึ้นและหายตามกรณีในข้อ 2 ทุกกรณี (unit test ต่อกรณี)
- [ ] ปุ่มในฉากใหญ่ ≥ 48 dp · ใช้ไอคอนนำ ข้อความเป็นรอง
- [ ] golden ใหม่: ฉากเลือกคลาส, แถบเมนูมีจุดแดง (TH + EN)
