## 2. โมจิเดินสองขา + rig ใหม่

- ท่าทาง: ยืนสองขา ตัวตรง สัดส่วนหัวโต (~2.2 หัว) แบบการ์ตูนผจญภัย หางยังอยู่ · ใช้มือ (อุ้งเท้าหน้า) ถืออาวุธ
- **Rig ใหม่ 10 ชิ้น** (เดิม 6): หัว, หู, ลำตัว, แขนหน้า (ข้างที่ถืออาวุธ), แขนหลัง, ขาหน้า, ขาหลัง, หาง, + หน้าอารมณ์ (สลับบนหัว) — แต่ละชิ้นมี **จุดหมุน (pivot)** และ **จุดติดอุปกรณ์ (attach point)**
- ท่า animation ทำด้วย rig (ขยับชิ้นส่วน) ไม่ใช่วาดทีละเฟรม: ยืน, เดิน, ตี (แต่ละประเภทอาวุธ), ร่ายเวท, หลบ, เจ็บ, ชนะ, นอน
- เครื่องมือ: เขียน rig เองใน Flame (ชิ้นส่วน + pivot + keyframe การหมุน/เลื่อน เก็บเป็น JSON) — ไม่ใช้ Spine เพราะมีค่าไลเซนส์และสไตล์เราเรียบพอ
- ภาพที่ต้อง gen ใหม่: ท่าอ้างอิงเต็มตัว 1 แผ่น + ชิ้นส่วน rig 1 แผ่น + หน้าอารมณ์ 1 แผ่น (prompt จะเขียนให้หลัง YK ยืนยันแผน)

## 3. ชุดและอาวุธที่มองเห็นได้ (ระบบตู้เสื้อผ้า)

### 3.1 ช่อง 8 ช่อง (แสดงบนตัวทั้งหมด)
| ช่อง | ติดที่ชิ้น rig | ตัวอย่างหน้าตา |
|---|---|---|
| อาวุธ ⚔️ | มือหน้า | ดินสอดาบ, ไม้เท้าพู่กัน, ค้อนยางลบ |
| หมวก 🎩 | หัว | หมวกถัก, หมวกนักผจญภัย |
| เสื้อ/ชุด 👕 | ลำตัว | เสื้อถัก, เสื้อเกราะผ้า |
| ผ้าพันคอ 🧣 | คอ (ลำตัวบน) | ผ้าพันคอลายทาง |
| ถุงมือ/ปลอกแขน 🧤 | แขนทั้งสอง | ถุงมือไหมพรม |
| รองเท้า 👢 | ขาทั้งสอง | บูทผ้า |
| กระดิ่ง 🔔 | คอ/เข็มขัด | กระดิ่งทอง |
| กระเป๋า 🎒 | หลัง | กระเป๋าเป้ถัก |

### 3.2 แยก "พลัง" ออกจาก "หน้าตา" (เหมือนระบบตู้เสื้อผ้าในเกมแนวนี้)
- ของแต่ละชิ้นที่ถักได้มี **แบบ (style)** — ถักได้แบบใหม่ครั้งแรก = **ปลดล็อกหน้าตานั้นในตู้เสื้อผ้า** ถาวร (แม้รีไซเคิลชิ้นนั้นทิ้งไปแล้ว)
- ช่องไหนก็เลือกได้ว่าจะ "ใส่หน้าตาแบบไหน" ไม่ผูกกับของที่ให้พลังอยู่ → เด็กแต่งตัวตามชอบได้โดยไม่เสียพลัง
- สมุดสะสม: หน้ารวมทุกแบบ — แบบที่ยังไม่ได้เป็นเงาดำ (แรงจูงใจถักต่อ)
- cosmetic ที่ขาย (IAP) ก็ใช้ระบบเดียวกันนี้ = แค่ "แบบ" ที่ปลดด้วยการซื้อ

### 3.3 แบบต่อช่อง (MVP)
- ช่องละ **3 แบบ** ตามเกรด (ขาว–เขียว / ฟ้า–ม่วง / ทอง–รุ้ง) + เกรดสูงมีสีต่างกันด้วย tint → **24 ชิ้นภาพ** ต้องวาดพอดีกับชิ้น rig
- อาวุธมี 3 **ประเภท** ที่ท่าตีต่างกัน: ดาบ (ฟัน), ไม้เท้า (ร่าย), ค้อน (ทุบ) — ประเภทอาวุธเปลี่ยน animation และสายสกิลที่ได้โบนัส

## 4. Stat 3 ชั้น

| ชั้น | Stat | หมายเหตุ |
|---|---|---|
| **หลัก** (ทุกช่องให้) | ❤️ HP · ⚔️ ATK · 🛡️ DEF · ⚡ ความเร็วตี | ค่าฐานของอุปกรณ์ |
| **รอง** (affix สุ่มบนของ 1–3 ตัว, คู่ stat/anti-stat ตาม GDD v0.4 §4.1) | คริ / แรงคริ · ตีติด · สวนกลับ · มึน · หลบ (แทนปุ่มหลบ) / แม่นยำ · ดูดเลือด · ฟื้นเลือด/วิ | ความลึกสำหรับผู้ใหญ่ |
| **พิเศษ** (affix หายาก เกรดม่วงขึ้นไป + ดันเจี้ยน) | ดาเมจสกิล% · ดาเมจใส่บอส% · ดาเมจเพื่อนสัตว์% · ลดคูลดาวน์% · ไหมพรมที่ได้+% · ปลาทองที่ได้+% · โอกาสได้เกรดสูงตอนถัก+% | ทำให้เลือก build ได้ (สายฟาร์ม vs สายตีบอส) |

- เด็กเห็นแค่ **พลังแมว 🐾** ตัวเลขเดียว + ลูกศรเขียว/แดง · ผู้ใหญ่กดดูหน้า stat ละเอียดได้
- "ของดีกว่า" สำหรับถักอัตโนมัติ = พลังแมวรวมสูงขึ้น (ไม่ใช่ทุก stat ≥ เดิม) — ตรงกับที่ต้นแบบทำอยู่
- ทุก stat ใหม่เพิ่มด้วยข้อมูล (ตาราง Attribute + buff engine) ไม่ต้องแก้สูตรหลัก

## 5. Idle ล้วน

- ตัดปุ่มหลบและการแตะสกิลเอง → สกิลร่ายเองตาม cooldown · หลบเป็นโอกาสจาก stat
- "!" ก่อนมอนตียังแสดง (อ่านจังหวะการต่อสู้ได้) แต่ไม่ต้องทำอะไร
- สิ่งที่ผู้เล่นทำ: ถักของ/เลือกใส่, ฟักไข่, อัพห้องสมุด, กดท้าบอส, เลือกความเร็ว, แต่งตัว, เข้าดันเจี้ยน
- **ความเร็ว x1 / x1.5 (ผ่านหน้า 5) / x2 (ผ่านหน้า 10)** — มีผลเฉพาะตอนเปิดเกม ไม่เร่งออฟไลน์/เวลาวิจัย
- **ถักอัตโนมัติ** ไม่ต้องตั้งเงื่อนไขเยอะ: เปิด/ปิด + "ของดีกว่า: เก็บรอเลือก / ใส่ทันที" · ของอ่อนกว่ารีไซเคิลเอง · เก็บรอได้ช่องละ 1 ชิ้น (ชิ้นที่ดีที่สุด)

## 6. ดันเจี้ยน (เฟสถัดไป)

- เป็น **GameMode plugin แบบ run** (`wt_mode_dungeon` ที่ MODE_PLUGIN_SPEC เตรียมไว้แล้ว) — สู้อัตโนมัติ ผ่านห้องทีละห้อง จบที่บอสดันเจี้ยน
- ดันเจี้ยน 3 แบบ ให้ของคนละอย่าง:

| ดันเจี้ยน | ได้อะไร | เอาไปอัพอะไร |
|---|---|---|
| ถ้ำคริสตัลสี | **อัญมณี** (stat รอง/พิเศษ) | ใส่ช่องอัญมณีบนอุปกรณ์ (ติดกับ "ช่อง" ไม่ใช่ชิ้น — เปลี่ยนของไม่เสีย) |
| โรงปั่นด้าย | **หินตีบวก** + ไหมพรม | ตีบวกช่องอุปกรณ์ (แทนการใช้ปลาทองล้วน) |
| ห้องสมุดลับ | **หนังสือสกิล** | อัพเลเวลสกิลแมว |

- **ห้ามเป็นระบบ energy** (GDD ห้าม): เข้าได้ไม่จำกัด รางวัลเต็ม 3 รอบ/วัน/ดันเจี้ยน หลังจากนั้นได้ 25% (เหมือนกติกาโหมดผจญภัย)
- ความยากหลายชั้น ปลดตามหน้าที่ผ่านในโหมดหลัก
- ใช้มอนชุดเดิมของแต่ละบท + บอสดันเจี้ยนตัวใหม่ 3 ตัว
