เรื่องกติกา
เลือกช่องผู้เล่นเลือกเองจาก 8 ช่อง: หมวก ผ้าพันคอ เสื้อ ปลอกแขน รองเท้า กระดิ่ง กระเป๋า ของเล่น · กด "สุ่มช่อง" ได้ EXP ตะกร้า +50%

การต่อสู้ & stat

Stat

ชั้นStatคู่กัน (anti-stat)
หลัก❤️ HP · ⚔️ ATK · 🛡️ DEF · ⚡ ความเร็วตี—
รองคริ / แรงคริกันคริ / ลดแรงคริ
ตีติดกันตีติด
สวนกลับกันสวน
มึนต้านมึน
หลบแม่นยำ
ดูดเลือดต้านดูดเลือด

เด็กเห็นแค่ พลังแมว 🐾 ตัวเลขเดียว

วิธีคิดดาเมจ

  • ดาเมจพื้นฐาน = max(ATK − DEF, ATK × 5%) ตีเบาแค่ไหนก็เจ็บนิดหน่อยเสมอ
  • สุ่มครั้งเดียวแบ่ง หลบ / ปกติ / คริ
  • คริคูณ max(1.5, แรงคริ − ลดแรงคริ)
  • stat รองทุกตัว = stat − anti มีเพดาน: คริ 60% · ตีติด สวน หลบ 40% · มึน 25%
  • สู้แบบผลแน่นอน (fixed-point + seed) จึงคำนวณรางวัลออฟไลน์ได้โดยไม่ต้องมีเซิร์ฟเวอร์

Buff engine

buff ทุกตัวมาจาก JSON (ชื่อ action + ค่า) และยิง buff อื่นต่อได้เมื่อเกิดเหตุการณ์ เช่น คริ โล่แตก ฆ่ามอน ทำให้ synergy ทั้งหมดเป็นข้อมูล เพิ่มได้โดยไม่ต้องแก้โค้ด

วิจัย Legend of Mushroom

วิเคราะห์ Legend of Mushroom v2.0.34 ด้วย REA แบบ static อ่านแค่ไฟล์ในแอป ไม่ได้รันเกม ไม่ได้ถอดตารางตัวเลขของเขา และไม่ได้ก๊อปโค้ด

ระบบของเขาเราเอาอะไรมา
เปิดกล่องได้อุปกรณ์วงจรเปิด → เทียบ → สวม/ขาย, auto-open พร้อมตัวกรอง, อัพเกรดตามช่อง → กลายเป็นตะกร้าถักเอง (ไม่สุ่มช่อง)
Buff engine ~85 แบบbuff = action + ค่า + hook, ยิง buff ต่อจาก event → synergy เป็นข้อมูล
สูตรดาเมจรูปแบบ DEF หักลบ + stat คู่ (ตัวเลขเป็นของเราเอง)
Pet + Scienceเพื่อนสัตว์ลงสนามจริง, ให้พลังตอนครอบครอง · ต้นไม้วิจัยใช้เวลาจริง
Rogue modeยืนยันว่า roguelite เดิมของเราเป็นโหมดเสริมได้
Gacha เติมเงิน, VIP, PvP, กิลด์, แชท, 66 กิจกรรมเทศกาลไม่เอา
